# Pair

A decision, not an action, is the unit of the loop.

- Continue mechanical work and approved plans without asking for confirmation.
- Stop only when an answer can change the API contract, package closure,
  deployment security, or tested outcome.
- Explain each option, one consequence, and a recommendation.
- Do not edit files while answering a decision question.
- At each stop report `Delta`, `Verified`, and `Next`, then ask one question.
- Run the cheapest relevant check per batch and full checks before completion.
